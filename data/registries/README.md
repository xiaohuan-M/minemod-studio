# 固定版本物品 ID

这里只保存事实性的原版注册 ID，不包含图像、游戏代码或 wiki 说明文字。来源 [PrismarineJS/minecraft-data](https://github.com/PrismarineJS/minecraft-data/tree/1df9432c07c81b47326e4fb1e06d3c8d723bf4aa)，固定提交 `1df9432c07c81b47326e4fb1e06d3c8d723bf4aa`。来源 README 的 License 段标注 MIT，并注明数据来源的额外许可可能适用；参见其原始声明，不将其素材再授权为本项目原创。

- Java 1.20.1：data/pc/1.20/items.json（依据上游 dataPaths.json）
- Java 1.21.1：data/pc/1.21.1/items.json
- Bedrock 1.21.60：data/bedrock/1.21.60/items.json

提取 name 字段、去掉 minecraft: 前缀、去重排序，排除不能作为合成原料的 air。不同加载器共享相同 Minecraft Java 版本的原版 ID 集合。此表不包含第三方模组内容，也不代表已做游戏实测。
