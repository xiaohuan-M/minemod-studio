多目标本地创作工坊
制作物品、方块、生物、配方、贴图与立方体模型；在动画工坊编辑关键帧并用于 Bedrock 实体。选择 Fabric、Forge、NeoForge 或 Bedrock 目标，导出源码与作品。 Java 编译需要 Docker，Bedrock 本地打包无需 Docker；支持范围随目标显示。
模型与 API 设置

保存多个文本或图像服务并即时切换。保存和切换不会发送模型请求。密钥保存在本机服务的数据目录，不会回传、写入浏览器存储或随项目备份导出；它与 .env 一样是本机私有配置文件。

新增服务配置

远程地址必须使用 HTTPS；本机可以使用 http://127.0.0.1:11434/v1 并省略密钥。文本与图像协议独立配置。

      规划方式

      生成规格会发送本项目的名称、需求文本、目标版本、当前规格、最近 12 条已完成修改的需求与摘要和修改要求；若选择构建修复，还会发送选定失败日志末尾最多 6000 字。连接测试只发送固定样例。服务商可能计费，程序不估算费用，也不自动重试。

      配置我的 API

      可直接使用页面上方“模型与 API 设置”保存并启用服务，无需重启。也可以在运行服务的电脑上，将 .env.example 复制为 .env，填写以下配置并重启；网页配置优先，切回“环境变量”即可恢复原配置。 

      MINEMOD_LLM_BASE_URL=https://your-provider.example/v1
MINEMOD_LLM_MODEL=your-model-name
MINEMOD_LLM_API_KEY=your-api-key

      本机接口可使用 http://127.0.0.1:11434/v1。若服务不接受 JSON 模式，设置 MINEMOD_LLM_JSON_MODE=false；仍会验证输出规格。连接测试通过只说明该接口能返回有效规格。
