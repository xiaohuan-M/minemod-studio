    规划方式

    生成规格会发送本项目的名称、需求文本和目标版本。连接测试只发送固定样例。服务商可能计费，程序不估算费用，也不自动重试。

    配置我的 API

    在运行服务的电脑上，将 .env.example 复制为 .env，填写以下配置并重启。密钥只保存在服务端文件中，不填入网页。

    MINEMOD_LLM_BASE_URL=https://your-provider.example/v1
MINEMOD_LLM_MODEL=your-model-name
MINEMOD_LLM_API_KEY=your-api-key

    本机接口可使用 http://127.0.0.1:11434/v1。若服务不接受 JSON 模式，设置 MINEMOD_LLM_JSON_MODE=false；仍会验证输出规格。连接测试通过只说明该接口能返回有效规格。
