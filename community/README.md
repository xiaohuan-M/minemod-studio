# 开放素材目录

此目录随源码分发、离线可用；不是托管在线交易平台。首批三组模型与程序贴图为 MineMod Studio 独立制作，按 [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) 贡献。模型/贴图是一组可编辑起点，用户可在导入后继续绘制和修改。

贡献方式：通过 GitHub Pull Request 修改 catalog.json，提供唯一 id、标题、描述、作者、明确许可与来源；只能提交自己拥有权利的素材或兼容许可素材，不复制 Minecraft 原版贴图。每个 assets 条目使用公开资源契约，不能包含脚本、远程 URL 或密钥。CI 校验类型、结构与来源；维护者审阅通过后合并。不同许可素材须在各自条目中保留许可文本/来源链接，不能套用本目录首批素材的 CC0 声明。

页面可以导入目录条目，也能导出和导入带校验值的 `.minemod-assets.json`，无需平台账号。来自外部的包始终重新分配资源 ID，不覆盖本地资源。
