# 0.2 功能与限制

| 能力 | 状态与边界 |
| --- | --- |
| 自带 LLM | Chat Completions 非流式文本；可选 JSON 模式；真实服务未联调 |
| 需求迭代 | 当前规格 + 修改要求；完整新规格校验后才替换，保留历史 |
| 构建诊断 | 用户选择失败日志，模型建议规格修正；不自动修改模板或运行任意代码 |
| 内容 | 物品、食物、5 类工具、闪电法杖、实心立方体方块；属性可视化编辑 |
| 合成 | 有序/无序，3×3 编辑、预览、引用与数量验证；原版 ID 尚未对照注册表 |
| 像素素材 | 本地绘画/PNG；16/32/64；LLM 像素数组草稿；无专业图片模型适配 |
| 3D 素材 | 静态 Java 立方体、单轴有限角度旋转；bbmodel 互通；无 mesh/动画/骨骼 |
| 3D 预览 | 编辑器几何投影、旋转、缩放与角度预设；不是 Minecraft 渲染器/角色装备实测 |
| 资源库 | 素材来源、许可、哈希；物品/方块贴图和物品模型绑定；不提供在线市场 |
| 项目 | 本地保存、重开、复制、规格导入/导出、20 版规格历史 |
| 工程 | 固定模板、确定性文件哈希、快照、文件差异与源码审查、完整源码包 |
| 编译 | Linux Docker 已真实验证，4 GiB / 2 CPU / 10 分钟、固定命令与镜像摘要 |
| 交付 | 经 JAR 结构和哈希检查后下载；完整源码 + JAR + 构建报告 + 安装说明 |
| 失败处理 | 日志、取消、超时、服务重启中断；旧成功产物保留 |
| Minecraft 平台 | 只实现 Java / Fabric 1.21.1；Forge、NeoForge、Bedrock、多版本均未实现 |
| 其他玩法 | 实体/生物、盔甲、GUI、维度、网络自定义协议、任意 Java 行为未实现 |
| 游戏实测 | 尚未完成；需要用户安装到独立实例验证 |

资源数量当前最多 500 项，每项目工程最多 100 个快照。没有自动清理；停止服务后备份完整数据目录，再整理不需要的测试目录。单进程本地应用，不提供账户、公开服务部署或多人协作。

当前支持范围内可不配置 API 完成全部手动创作与真实编译；使用 LLM 的步骤需要用户自带可用端点。开源许可和源码完整可用，不代表以上尚未实现的能力已经存在。

### 新增目标

Fabric 1.20.1（Java 17）已通过完整样例真实编译；Fabric 1.21.1 保持兼容。Bedrock 1.21.60 支持普通物品、食物、方块、贴图与配方，导出 MCADDON，完成包结构校验，尚未游戏实测。Bedrock 工具/法杖/Java 物品模型不支持。目标选择在新建项目表单，能力由注册表提供。

### 模型工作流更新

本地 Three.js WebGL 预览支持真实贴图、点选立方体、相机环绕、UV 区域/旋转/隐藏面、单轴旋转与 rescale、手持/头部/物品栏/掉落显示变换、人形比例参考和预览 PNG。编辑器已拆为独立模块；没有第三方 CDN 请求。Java 模型导出与 bbmodel 往返保留上述属性。人形预览并非 Minecraft 游戏实测；网格和骨骼动画仍不支持。
