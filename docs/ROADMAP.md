# 实现进度与后续验收

0.3 已完成五目标注册表、四个 Java 模板真实构建、Bedrock 打包、内容/配方/实体编辑、图片/像素/UV/模型/动画工坊、持续创作、开放资源目录、完整备份、可重建的本地发行包。证据见 FEATURES.md 和 TEMPLATE-VALIDATION.md。

后续按可验收行为推进，不能以修改版本字符串或添加按钮代替实现：

1. **游戏验收**：四套 Java 独立客户端/服务端与 Bedrock 1.21.60 测试世界，逐项检查注册、配方、掉落、工具、法杖、实体、渲染与动画；记录游戏版本和失败复现。
2. **真实服务**：用户提供可用服务后，验证文本/视觉/图像协议、取消、费用与质量；当前按用户要求跳过。
3. **玩法扩展**：盔甲、自然生成、掉落/行为图、交互界面；每项新增独立规格规则、目标映射和游戏验收。
4. **美术扩展**：分层骨骼、关键帧曲线、Java 自定义实体渲染、更多 Blockbench 格式；不能静默丢失导入字段。
5. **更多版本**：逐个建立模板/注册表，真实编译并游戏验证；不承诺已支持 1.7.10–26.3 全部版本。
6. **跨平台发行**：Windows/macOS Docker 实际构建、可选桌面包装和签名；当前交付本机网页程序。
7. **协作服务**：若需要托管市场、远程访问或多人同步，先设计认证、数据库事务与素材治理，不能直接公开当前本地 HTTP 服务。

每个功能块独立提交推送。项目仍在持续开发，未完成的范围在产品界面和文档中保持可见。
