# 0.5 审查记录

基线 e50dc0d（0.4）。审查范围为 ModSpec、五目标资源生成、内容/实体编辑、目标能力展示与备份链路；不等于整个项目已完成安全审计或游戏验收。

| 发现 | 处理 | 回归证据 |
| --- | --- | --- |
| 方块/实体只能使用固定掉落，无法形成自定义资源获取玩法 | 增加声明式掉落与五目标生成 | 规格边界、五目标输出、真实构建 JAR 检查 |
| 内容/实体表单重建对象会丢失新扩展的掉落字段 | 编辑同类对象时保留 loot，掉落编辑独立使用稳定 ID | 浏览器修改实体生命和方块硬度后保留掉落 |
| 目标说明按 edition 硬编码，遗漏实体/动画能力 | 根据目标注册表渲染已知能力名称 | 浏览器目标切换检查 |
| 完整示例仍声称不含武器、未对照原版注册表 | 改为当前行为和实际验证边界 | 示例通过规格与工程回归 |
| Bedrock 打包未检查掉落表引用 | 校验 block/entity 组件引用的文件存在且是有效 JSON | 删除所引文件后打包必须失败 |

保持旧记录不填充新默认字段；缺失 loot、空 loot、带条目 loot 含义分别验证。真实 API 按要求跳过；游戏实测、复杂骨骼、更多版本和行为扩展仍未完成。
