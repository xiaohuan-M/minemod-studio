# 模型与骨骼数据 · 0.14

静态 `model` 素材继续使用 Java 立方体格式：1–128 个立方体、0–16 UV、单轴 0/±22.5/±45 度旋转、显示姿态和可选 16/32/64 RGBA 贴图。它可以进入 Java 物品或五目标方块；骨骼不会被偷偷展平或丢弃。

`animated_model` 可选 `bones`，表示与具体加载器无关的层级中间格式。完整样例见 [rigged-guardian.json](../examples/rigged-guardian.json)。

```json
{
  "elements": [{ "from": [4, 0, 4], "to": [12, 16, 12] }],
  "bones": [{
    "name": "身体", "pivot": [8, 8, 8], "rotation": [0, 20, 0], "elements": [0]
  }],
  "clips": [{
    "name": "idle", "duration": 1, "loop": true,
    "tracks": [{ "bone": 0, "keyframes": [
      { "time": 0, "rotation": [0, 0, 0] },
      { "time": 1, "rotation": [0, 30, 0] }
    ] }]
  }]
}
```

- `bones` 最多 128 项、32 层。`parent` 是父骨骼索引，省略表示独立根；禁止环。名称可用中文，1–80 字，唯一且不含控制字符或保留原型键名。
- `elements` 列出骨骼拥有的立方体索引，每个立方体必须且只能归属一个骨骼。允许空骨骼作为父控制器。
- `pivot` 使用模型像素的全局绑定坐标，范围 ±80；子节点的局部偏移为自身中心减父中心。`rotation` 是绑定姿态的 ZYX Euler 角，范围 ±360 度。
- 层级轨道用 `bone`；历史平级模型继续用 `element`，不能混用。每轨道关键帧时间唯一，片段名为小写 ID；最多 8 片段、每片段 0.1–30 秒、全模型 512 关键帧。旋转 ±360、位移 ±80、缩放 0.01–4，缺省为零旋转/位移和单位缩放。
- 只支持线性插值，不执行表达式、Molang、脚本、任意网格或蒙皮。骨骼可以多轴绑定；立方体本身仍使用静态模型的基本格式。

旧素材读取时不补 `bones`，保留原始规范形状与 SHA。编辑器提供明确转换，保留立方体、绑定数值及关键帧；Java `rescale` 必须先烘焙。删除只接受没有立方体、子节点或轨道的叶节点，并同步重映射索引。改父级和归组先调用共享规则校验，再更新 Three.js，避免循环图进入渲染器。

bbmodel 导出包含嵌入 PNG、嵌套 outliner、分组和动作。自己的顺序元数据保持索引往返；普通文件按遍历顺序导入。任意立方体 Euler 绑定可以转为子骨骼，独立通道关键帧时间会取并集并插值，不把缺失通道突然重置。静态骨骼文件自动获得空 idle 片段。重复/缺失引用、表达式和不支持的插值明确拒绝。

Bedrock 资源输出父子骨骼、每组多个立方体及按骨骼名称寻址的动作。保守包围范围覆盖绑定和各片段位移/缩放，半径超过 1024 模型像素时拒绝目标导出；不静默裁切。UV 面旋转和 Java rescale 在 Bedrock 需要先烘焙。

四个 Java 目标可绑定静态或层级动画实体模型，直接编译为包内四边形与固定渲染器，保留面 UV 旋转、隐藏面、单轴 rescale 和父子多轴动作，无额外动画模组。落地点为 `[8,0,8]`，16 模型像素为一格；选中 `walk` 时随移动播放，其他片段持续播放，非循环片段停留末帧。可见范围保守覆盖动画，半径超过 64 格拒绝；实体行为和物理体积仍由僵尸/牛原型决定。Java 物品/方块静态导出继续拒绝骨骼模型，不隐式展平。

`skeleton.mjs` 是浏览器和服务端共享的纯数据规则；`skeleton-exchange.mjs` 负责文件/目标格式，`animation.mjs` 维护旧格式兼容与统一验证。贴图、来源、许可、不可变素材及版本/备份沿用既有存储，不另起一套历史系统。文件互通与包检查不代表已启动 Blockbench 应用或完成游戏客户端视觉验收。
