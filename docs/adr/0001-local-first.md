# ADR 0001 · 本地服务与单版本起步

日期：2026-10-22。状态：接受为 M0 基线。

## 背景

产品需要访问本机工程与后续编译工具，用户希望开源且能自带模型 API。云平台的账号、积分和市场能力并不是本地首版闭环的前提。

## 决策

- 以本地浏览器 + Node.js 24 服务起步，不先引入桌面打包和云部署。
- M0 使用无第三方依赖的 ES modules 与静态界面壳，降低环境成本；应用复杂后可通过独立 ADR 引入框架与数据库。
- 数据默认本机保存，不自动同步或上传；模型、生成与执行分层。
- 第一个构建目标只验证 Fabric / MC 1.21.1 / JDK 21，不复制参照产品的全版本宣称。
- M0 的计划使用 mock，并始终标明演示；能力状态是面向用户的真实契约。

## 代价与后续

原生静态 UI 不适合长期承载复杂模型编辑；JSON 也不适合高并发任务事件。需要时可逐层替换，领域模型与 API 保持独立。手机只能作为布局目标，不能直接访问电脑服务；远程模式须另做认证、授权与网络设计。构建隔离、模板版本和桌面安装分别记录新 ADR 后推进。
