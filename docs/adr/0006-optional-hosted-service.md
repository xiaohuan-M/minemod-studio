# ADR 0005：可选托管服务与本地创作内核分离

本地工具不需要注册、平台积分或公共内容服务。参考产品的在线能力另设 Hub，不把本地回环 HTTP 直接暴露到公网。

Hub 是独立 HTTP 入口，校验配置的公共 Host/Origin，提供密码和可选微信授权、会话、邀请、积分账本、线路、激励审核和资源市场。Node 内置 SQLite 保存需要事务的共享元数据，WAL、外键、余额约束、唯一账本引用和单进程写锁保证本进程的并发一致性；不使用本地项目 JSON 模拟计费事务。

每个账户对应独立数据根和完整创作服务。服务只监听随机回环端口，网关认证后才转发，移除外部凭据与转发头。原有项目修订检查在多设备间继续生效，冲突返回 409；不会静默覆盖。空闲工作台可关闭，持久化数据继续保留；执行任务中的工作台不驱逐。这里只是账号隔离，不是对同宿主恶意代码的虚拟机隔离。

平台线路密钥只来自服务端环境。模型专用令牌不可访问项目或账号 API；网关用 SQLite 预留积分，成功且用量已知时结算，失败/用量未知退款，重启退回中断请求。服务返回的 token 用量是计费依据，不冒充独立测量。超出预留额度的部分由运营者承担，不追加透支。

市场使用不可变修订，作者确认来源和许可，管理员按具体修订审核。新版等待审核时保留已公开旧版；上传者不能替换别人的内容。导入到个人素材库后保留内容、来源、许可和哈希，不执行发布者代码。资源包限 30 项/32 MiB，素材仍受核心校验。

第一版面向自行部署的个人和可信团队，默认邀请注册。公共匿名 SaaS 所需的恶意代码隔离、磁盘/容器租户配额、内容举报与申诉、审计保留、横向扩容、付费充值、运维监控和第三方安全审计不在这个服务的当前保证内。部署者需要自己的 HTTPS、网络出口策略和模型/微信凭据；仓库不会附赠商业 API 或可公开使用的公益服务。
