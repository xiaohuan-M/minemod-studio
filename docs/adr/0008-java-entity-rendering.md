# ADR 0008：由共享模型编译 Java 实体渲染数据

状态：采用。日期：2026-10-25。

现有模型/动画素材可以在网页编辑、导出并进入 Bedrock，但 Java 生物使用原版外形，导致同一素材无法完成四个 Java 目标的交付。

保留同一份受验证的素材格式。`entity-mesh.mjs` 在源码生成阶段把立方体编译成四边形、UV、法线和骨骼相对变换；复用项目已有 Three.js 数学与立方体拓扑，不引入另一套依赖。层级绑定使用 ZYX；旧平级模型保持 XYZ 叠加动画，rescale 和隐藏面、面 UV 旋转也保留。坐标以 `[8,0,8]` 为实体落地点，16 模型像素为一格。

固定 `StudioEntityRenderer` 读取随模组打包的 JSON。Fabric Yarn 与 Forge/NeoForge 官方映射、1.20/1.21 顶点接口分开适配；不增加第三方动画模组，不把客户端类加载到专用服务器入口。父子索引、轨道索引在生成时建立，渲染时只遍历子树与对应轨道。保守包围半径覆盖各片段，超过 64 格拒绝，视锥扩展仍遵守实体距离检查。

渲染器和数据放在独立 `studio.minemod.runtime.m_<modId>` / `assets/minemod_runtime_m_<modId>` 命名空间，不属于 AI 代码可修改范围，也不占据玩法代码上下文。它只读取自己的固定包内资源；模型 JSON 没有表达式、任意资源路径或可执行逻辑。

显式贴图覆盖模型内贴图。无自定义模型时保留原版模型和 64×64 UV 约束；自定义模型支持 16/32/64 贴图。`walk` 在移动时播放，其余选中片段按实体存在时间播放；非循环片段停在最后一帧。原型 AI、生命、掉落与碰撞体积保持既有规则，本功能不实现装备层、原版攻击/受伤姿态混合、任意网格或新的物理体积。

验证必须分开记录：数学/源码/浏览器检查、四目标真实编译、断网服务器 GameTests、实际客户端画面。任何一层通过都不能替代其余层，也不能证明真实模型的美术质量。
