# ADR 0004 · 持久创作任务与完整作品版本

状态：已采用，0.6。

原来的 HTTP 接口分别运行模型、素材、生成器和构建器，用户需要逐步衔接。规格历史又无法代表带素材、源码和产物的整轮作品。将这些操作继续堆进 server 路由会使取消、恢复和并发控制难以维护。

采用独立 CreationManager 应用服务，注入项目、素材、工程、构建和版本端口。每步持久化事件、调用状态、项目 revision 和产物引用；刷新网页不取消后台任务。进程重启将未终结任务标为 interrupted，重新确认后只运行未完成的步骤。模型运行时配置不可修改，项目写入锁阻止手工操作与任务相互覆盖；模型返回后再次检查 revision。

用户可以一次选择本轮服务、素材范围、调用/修复上限和构建网络权限。此授权仅涵盖本轮任务；每次实际构建仍保存具体工程哈希和批准记录，不授予任意命令或宿主文件访问。取消不删除已完成内容；服务关闭须等待任务和构建停止、HTTP 关闭及写锁释放后再通知调用方。

ProductVersions 保存完整项目状态和不可变素材、工程、成功产物的关联清单。恢复前自动保存当前状态，恢复推进 revision 并清除执行批准。完整备份验证和迁移版本，重映射项目/构建 ID；导入工程仍保留 imported 标记，不能因为恢复了版本就直接执行。

当前 JSON 存储仍不具备跨文件断电事务。中断若恰好落在项目提交与任务记录提交之间，将以 revision 不匹配停止，要求从保留的项目状态发起新轮，避免盲目重复调用或覆盖。后续多人服务需要独立事务存储，此选择不代表完整托管平台已完成。
