# ADR 0003：可维护的模块化本地工坊

状态：实施中。2026-10-22。

采用模块化单体：领域层定义目标、规格、素材、版本和任务；应用服务编排用例；适配器分别承担 HTTP、持久化、模型协议和构建。当前原生 Node 服务保留，已验证的核心通过契约演进，不为换框架重写所有功能。网页和未来桌面壳使用同一用例接口。

生成器使用 Strategy / Registry：目标版本是经过验证的清单，适配器将同一规格转成对应文件，不在 HTTP 层拼 Java 或 Gradle。支持范围由能力清单控制，不能把目标下拉框当成兼容性。模板/包装器/运行器锁版本并记录校验信息。

规格验证采用 Ajv 2020 JSON Schema + 跨字段领域规则，替换只支持子集的自制 schema 解释器。新增 TypeScript 契约用于适配器边界；既有 JS 渐进迁移，不能因有一个 types 文件而宣称全库严格类型化。

前端按项目、会话、内容、素材、预览、工程拆模块。Three.js 负责纹理化 3D 和相机/变换，仍保留原始资源模型作为事实来源；不以渲染对象作为存储格式。原生 PNG 解码由 pngjs 完成，先限制输入字节、像素尺寸与解码结果。Prettier 统一格式，Playwright 流程检查放进仓库而不是只留在个人临时脚本。

应用服务必须依赖显式参数而非 HTTP request；可单元/契约测试。JSON 存储先增加独占写入与完整备份契约；长期需要多进程写入或大量任务时再迁移 SQLite，不能仅引入数据库名而不完成一致性迁移。用户数据需要迁移验证和可恢复备份。

依赖理由与许可证见 docs/research/OPEN-SOURCE-REVIEW.md。发布包提供锁文件、源码、依赖许可、检查结果与安装说明。第三方可执行插件没有自动安装权；将来插件以显式清单/版本/能力声明加载，不让模型自行安装任意包。
