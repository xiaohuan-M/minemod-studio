# ADR 0007：兼容历史的层级模型中间格式

原动画把一个立方体等同于一个独立根骨骼，无法表示手臂分组、父子关节或多轴绑定。新增可选 `bones` 数组，骨骼明确拥有立方体、引用父索引，并携带世界绑定中心和 ZYX 姿态；动画轨道改用 `bone`。历史模型没有这个字段时继续按原结构验证，不迁移或重写已有哈希。

规则在一个没有 Node/HTTP 依赖的纯模块实现，服务端与浏览器复用。唯一归属、深度和环在进入 Three.js 前检查；删除节点同步重映射父级与轨道。编辑器操作都产生新草稿，保存仍创建不可变素材，因此不会破坏已编译版本。

文件交换与引擎输出分离：bbmodel 使用嵌套分组，Bedrock 使用命名父子骨骼和几何/动作。导入可将非 Java 立方体旋转提升为子骨骼，以保留绑定，而不是强制展平；独立动画通道按时间并集采样。Java 静态格式无法表达层级，明确拒绝，等待客户端渲染适配，而不输出看似成功的残缺模型。

独立素材工坊从隐藏的项目区域移出，绘制、生成和文件互通不依赖空的模组项目。项目内容和工程编辑仍在项目区域，素材保留跨项目复用。自动 Bedrock 生物生成直接请求骨骼动作，并保留供应商生成的片段；固定空 idle 仅用于兼容旧的静态结果。

规范化、往返、错误图、动作范围、完整版本与迁移分别验证；浏览器实际比较动画前后画面，执行分组/拒绝环、bbmodel 往返及真正 MCADDON。没有凭据的真实模型效果、原生 Blockbench、Bedrock 客户端视觉和 Java 自定义生物渲染不由这些结果推断。
