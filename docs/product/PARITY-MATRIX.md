# AutoMods 公开功能逐项核对

**结论：MineMod Studio 0.8.0 尚未完成参考网站全部功能，不能作为功能对等的完整开源版验收。** 目前是能在本机进行受限内容创作、素材编辑、源码生成及编译/打包的开源工坊。已有可运行代码和真实产物，不代表公开宣传的整条 AI 创作链路已经实现。

核对日期：2026-10-25。参考：[AutoMods 首页与 FAQ](https://automods.cn/#faq)。重新读取整个公开首页，覆盖对话制作、模型/贴图工坊、全部功能、版本、FAQ；未登录其工作台，也没有验证对方宣传效果。以下只对照公开介绍，不猜测其内部实现。页面 HTML 的 SHA-256 为 `321bcd16206bf22d68883622163b91b08ce1e72baa7448c6f319c1bcc5115fdd`；未将对方页面、图片或品牌素材纳入本项目许可。

实现基线：0.8.0；0.5 历史基线为 `fc7977f`。最终交付目标见 [任务书](DELIVERY-BRIEF.md)，具体支持边界见 [功能清单](../FEATURES.md)。文中的“已实现”只表示该行限定行为已经有实现；验证列单独说明证据。真实模型接口按用户要求跳过，因此模拟 HTTP 成功不代表真实 AI 效果。编译与包结构通过也不代表游戏可玩。

## 9. 与“完整交付”之间的关键差距

这不是只剩界面打磨。缺口横跨核心产品流程和底层架构：

1. **AI 执行流程**：已有持久任务、自动素材/构建、规格级有限修复和中断恢复；已有版本 API 检索与受控代码变更/修复，但尚未通过真实模型效果和游戏运行验收。不能通过放开任意 shell 来冒充实现。
2. **完整作品版本**：0.6 已关联并可恢复完整版本；自动任务每轮保存，手工模式需显式保存。尚无自动保留期/清理器或跨文件断电事务。
3. **模型与游戏能力**：立方体数据、平级动画和原型实体无法表达完整模型/行为。需要模型中间格式、层级动画、装备/实体渲染及逐目标能力映射。
4. **在线产品能力**：本地 JSON 单写者和回环 HTTP 不支持账户、市场、同步和计费。需要独立服务边界、认证、事务存储及发布/授权流程；不能直接将现有本地端口暴露公网。
5. **验收**：真实 API 按要求暂缓；游戏测试尚未开始。Windows/macOS 应用 CI 不等于这些系统上的 Docker 或 Minecraft 实测。只有补齐相应证据，才能宣称整条创作流程可交付。

MIT 源码、BYO API、离线手工编辑、私有设置、完整备份、素材来源、明确版本和构建哈希是本项目已有价值，但不是参考站缺失功能的替代证明。没有双方质量/性能比较，不能声称已经“全面超越”。也不以未加权的功能条目数量计算完成百分比。
