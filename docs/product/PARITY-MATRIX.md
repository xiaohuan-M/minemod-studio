# 公开功能对照与验收

来源：https://automods.cn/（2026-10-22 读取首页与 FAQ；未登录私有产品）。对照是功能目标，不是对参考产品宣传真实性的独立验证。此表随实现更新。

| 参考能力 | 本地开源实现/优化目标 | 验收证据 | 当前缺口 |
| --- | --- | --- | --- |
| 对话制作与连续修改 | 持久化会话、上下文边界、逐次确认、版本关联 | 服务契约 + 浏览器流程 | 0.2 仅单次指令，无完整会话 |
| AI 构建多方案 | 多个玩法/数值/美术方案，选择后生成 | 模拟 API + 选择/版本冲突测试 | 待实现 |
| 真编译与自动修复 | 固定 runner、日志诊断、有界修正、明确任务状态 | 实际 Gradle + 失败/取消/恢复 | 目前仅规格诊断 |
| 背包与九宫格 | 可搜索内容、配方编辑与注册表校验 | 浏览器 + 引用测试 | 无原版 ID 注册表 |
| 完整历史 | 规格、素材引用、源码与产物关联，可恢复 | 回退后哈希/旧产物验证 | 规格历史和工程历史尚未统一展示 |
| 概念图/参考图/三视图 | 独立图像 provider、参考输入、图像结果和像素转换 | 图片接口模拟 + 本地转换 | 0.2 只有文本像素数组 |
| 方块风格模型 | 纹理化 3D、UV、显示变换、静态 bbmodel | roundtrip + 浏览器/WebGL | 0.2 只有纯色几何预览 |
| 生物/动画/装备 | 明确模型格式与渲染适配；动画和角色装备实际集成 | 导入/导出 + 目标构建 + 游戏验证 | 未实现 |
| 我的资产 | 来源/许可、搜索标签、不可变版本、可分享资源包 | 往返导入导出与引用检查 | 无搜索标签/资源包 |
| 模型市场 | 开放的可审查目录 + 本地导入/分享，无平台锁定 | 目录校验 + 资源导入 | 无公共目录 |
| 多版本/加载器 | 显式目标注册表 + 独立模板与能力检查 | 每个目标真实构建记录 | 仅 Fabric 1.21.1 |
| Bedrock 加载项 | 标准 behavior/resource pack + mcaddon | 包结构/资源引用验证 + 实机导入 | 未实现 |
| 网页/客户端 | 本机网页完整工作台，桌面包装复用应用核心 | 可重现发行包、启动/升级测试 | 当前需 Node + 可选 Docker |
| 积分/公益线路/登录 | 不复制封闭积分系统；自带服务与用量，用户拥有数据 | 公开源码、许可、无强制账号 | 多服务配置/用量界面待实现 |

“超越”必须落到可测量的改进：离线可用、可切换服务、可恢复数据、完整源文件、公开扩展契约、费用透明、错误可诊断、可重复构建。不得写成未经对照实测的性能或质量优越承诺。
