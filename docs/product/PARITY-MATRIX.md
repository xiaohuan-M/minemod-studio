# 公开功能对照与验收

来源：https://automods.cn/（2026-10-22 读取首页与 FAQ；未登录其私有产品）。对照描述公开功能目标，不是对该产品效果或宣传的独立验证。完整覆盖尚未完成，以下区分交付能力与差距。

| 参考能力 | 0.4 本地开源实现 | 证据 / 剩余差距 |
| --- | --- | --- |
| 对话制作、连续修改 | 100 次持久记录、12 次上下文、规格版本绑定、逐次调用 | API/浏览器通过；真实服务按要求跳过；非流式 |
| AI 构建多方案 | 2–4 方案、玩法/数值/美术/验收、选择后生成 | 模拟服务与浏览器通过 |
| 真编译、自动修复 | 四个 Java 目标真编译；失败日志诊断与修正规格 | 无任意代码级自动修复；游戏未测 |
| 背包、九宫格 | 内容卡片、配方编辑与目标版本原版 ID 校验 | 引用与浏览器回归通过 |
| 历史版本 | 规格恢复、素材不可变、工程/产物保留、完整备份迁移 | 浏览器已覆盖含动画/产物的完整往返；历史界面分规格与工程 |
| 概念/参考/三视/细节图 | 独立 Images API，选定参考图 edits，PNG 库与像素转换 | 模拟协议与本地转换通过；未验证真实画质 |
| 文本/图片生成模型 | 文本结构化立方体、可选视觉 PNG、校验后进入编辑器 | 不含外部专用 3D 生成服务，模型质量未实测 |
| 纹理模型与姿态 | 本地 WebGL、UV、贴图、手持/头戴/物品栏、bbmodel | 浏览器/往返通过；无 Minecraft 渲染实测 |
| 生物与动画 | Java 僵尸/牛原型，Bedrock 自定义立方体根骨骼/线性动画/行为 | 四 Java 样例编译，Bedrock 引用校验；无嵌套骨骼/Java 动画实体/盔甲 |
| 我的资产 | 来源/许可/哈希、搜索、资源包迁移 | API 与备份回归通过；无标签体系 |
| 模型市场 | 随源码分发的 CC0 目录、导入、可分享资源包、PR 贡献 | 开放目录可审查；非托管在线市场 |
| 三加载器、多版本 | Fabric 1.20.1/1.21.1、Forge 1.20.1、NeoForge 1.21.1 | 全部真编译；未覆盖 1.7.10–26.3 宣传范围 |
| Bedrock 加载项 | 1.21.60 物品/食物/方块/配方/实体/动画、MCADDON | 浏览器交付通过；工具/法杖/游戏导入未完成 |
| 本地网页/客户端 | 本机网页、附运行依赖的 ZIP、启动脚本、完整源文件 | 要求 Node24.5+；不是签名桌面客户端 |
| 手机、跨设备续作 | 窄屏 UI、完整项目文件迁移 | 不是远程访问/实时云同步；本机监听 |
| 积分、公益线路、登录 | 自带模型服务、网页多配置即时切换、本地所有权、token 记录、无强制账号 | 不复制平台积分或社交激励系统；费用由服务商计费 |

优化集中在可检查的属性：无平台锁定、无 API 手工创作、本地数据可恢复、源文件与来源完整、依赖/模板锁定、构建与游戏证据分开、扩展边界明确。未进行双方产品质量/性能对照测试，不作“全面超越”的效果承诺。
