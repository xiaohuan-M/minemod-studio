# 自行部署共享工作室

本地创作默认继续使用 `npm start`，无需账号或积分。可选 Hub 将同一个完整工作台放在经过认证的入口后，支持账号独立项目/素材、跨设备接续、审核市场和平台线路。代码与本地版均为 MIT；数据库不依赖云厂商。

## 本机试用

Node 24.5+，在仓库目录运行。用环境变量设置首次管理员，**不要把真实密码或 API Key 写进 Git**：

```sh
export MINEMOD_HUB_ADMIN_USERNAME=admin
export MINEMOD_HUB_ADMIN_PASSWORD='替换为至少十位的随机密码'
npm run hub
```

访问 `http://127.0.0.1:4320`。管理员在 `/hub` 生成一次性邀请码，其他用户使用邀请码注册。默认赠送 1000 平台积分，UTC 每天签到 10 分；投稿需要管理员审核才奖励。积分不是现金，没有自动充值或支付功能。密码保存为带随机盐的 scrypt 派生值；会话/API 令牌仅保存 SHA-256 摘要。改密撤销原有令牌和会话。

数据位于 `.minemod-hub`（可用 `MINEMOD_HUB_DATA_DIR` 更改），必须由运行服务的系统用户独占访问。备份前先停止进程，整体备份该目录，包括 SQLite/WAL 及 users 子目录。个人项目 ZIP 只包含个人作品，不能替代服务整体备份。单进程 SQLite 服务，不可用多个实例同时写同一目录。

## 模型与积分

不配置平台线路也能登录、使用手工编辑、市场及自己的 API。普通用户的自带 API 域名必须由管理员在 `MINEMOD_HUB_PROVIDER_HOSTS` 中列出，以逗号分隔；线路域名也自动允许。只允许 HTTPS。管理员是可信运营者，可配置额外地址；本地版继续支持自己的回环兼容服务。

平台线路从 JSON 文件读取，格式见 `examples/hub-routes.json`。将副本放到数据目录外的私有配置目录，设置：

```sh
export MINEMOD_HUB_ROUTES_FILE=/absolute/private/routes.json
export MINEMOD_HUB_COMMUNITY_KEY='服务端注入的真实密钥'
npm run hub
```

每条线路有唯一 ID、展示名、兼容 `/v1` 基址、模型、密钥环境变量名，以及输入/输出每 1000 token 的非负整数积分。两个价格均为 0 表示由运营者承担费用的公益线路，不表示上游 API 免费。示例模型和地址是用户选项，未带真实密钥，未验证真实效果。

工作台请求默认使用选中的平台线路；个人启用的自带配置优先。在账户页选择线路，空闲时即时切换。每次调用先根据消息 UTF-8 字节数和最大输出预留额度，响应返回有效用量后按实际 token 结算，向上取整；额度不足时不会调用上游。未知用量/失败全额退款，不伪造账单；超预留费用由运营者承担。图片内容的真实 token 计价可能高于预留值。个人自带 API 的费用由对应服务商收取，不经过平台积分。

账户页可生成 30 天模型专用令牌，外部兼容客户端使用：

```
Base URL: https://你的域名/api/hub/llm/线路ID/v1
API Key: 账户页生成的令牌
Model: 该线路配置的模型
```

令牌只允许模型 API，不能读取项目；可主动撤销。上游 Key 不会传给客户端。当前网关仅支持非流式 Chat Completions；不代理任意 URL，不开放上游文件/工具执行接口。

## 远程与手机

使用你控制的 HTTPS 域名与反向代理，将流量转发到回环端口。配置 `MINEMOD_HUB_PUBLIC_ORIGIN=https://你的域名`，不要附路径或末尾斜杠。反向代理必须保留此公共 Host；服务不信任外部 Forwarded/X-Forwarded-*。同源浏览器写入强制检查 Origin，HTTPS 下 Cookie 使用 Secure、HttpOnly、SameSite=Strict。代理需要允许至多 32 MiB 资源包和足够的模型响应超时。

手机、平板、电脑访问同一 HTTPS 地址、登录同一账号即可访问持久化项目。项目修订冲突会提示刷新，尚无离线自动合并。同一账户的并行模型/创作限制继承本地内核；`MINEMOD_HUB_MAX_WORKSPACES` 默认最多 4 个活跃工作台，空闲实例会回收。未执行真实手机/平板硬件验收。

Java 构建仍需要宿主 Docker。建议先在 Linux 宿主直接运行 Node Hub 与 Docker，通过 HTTPS 代理提供访问。**不要未经路径映射和租户资源配额设计就把 Docker socket 挂入通用 Web 容器**。托管进程使用 Docker socket 的权限等同于高权限宿主操作，需要可信运营者和专用机器。默认邀请注册面向可信团队；开放匿名注册需要额外的出口限制、磁盘和容器配额、审计与安全评估。

## 微信网站应用

设置 `MINEMOD_WECHAT_APP_ID`、`MINEMOD_WECHAT_APP_SECRET`，在微信开放平台配置网站应用授权回调域名。入口使用官方 `qrconnect`，一次性 5 分钟 state 与独立 HttpOnly 浏览器 Cookie 绑定，服务端通过官方 token 端点交换授权码。首次登录创建账号，遵守与普通注册一致的邀请码策略；旧用户再次登录不会重复赠分。

这是协议实现，未提供真实微信凭据，真实扫码和平台资质配置未验收；未配置时入口隐藏，密码登录可独立使用。不会把普通二维码图片冒充已接通微信身份。

## 模型市场与审核

在创作台保存素材后，到 `/hub` 选择自己的素材或上传本项目资源包，填写名称、许可和来源并确认分享权利。发布进入待审，只有管理员批准的具体版本公开；新版待审不替换旧公开版。支持搜索、收藏、下载、导入个人库、更新和下架。来源和许可由作者声明，软件校验不等于第三方权利鉴定。当前无支付交易、第三方登录绑定、举报申诉或恶意内容自动识别。
